Panopticon
模式
只对这个浏览器生效，换一台设备要重新选。
缩放
把文字和界面整体放大或缩小，像 Windows 的“缩放与布局”。跟模式一样只对这个浏览器生效：大屏幕和手机可以各设各的。
配色方案
点一下，三处颜色一起换，之后还能单独改。下面的颜色都存在服务器上，手机和电脑看到的一样；选了马上生效，不用保存。
磁贴
总览里一切正常的机器磁贴。红色和黄色留给“需要关注”和“接近阈值”，选太接近的颜色会分不清。
曲线
总览里每台机器最近 1 小时的曲线。
状态栏
底部那一条。有机器需要关注时，最左边那格照样是红色。
谁看哪台机器
“自动”按机器名固定分一个人。选了马上生效，所有设备一起换。
表情
每人三种，磁贴按机器状态换。留空就用默认的（框里灰色那个）。最多 24 个字。
一切正常接近阈值离线或需要关注
告警阈值
CPU、内存、磁盘使用率超过这个百分比就告警；看板上的红色也用同一套阈值。
飞书
群设置 → 群机器人 → 添加"自定义机器人"，把 Webhook 地址填在这里。
测试用的是已保存的配置，改了 Webhook 要先保存。
邮件
上报过的机器会一直被盯着，离线超过 3 分钟就告警。机器退役或卸掉 agent 后在这里移除； 移除后如果它又开始上报，会自动回到列表里。
一键部署青源 agent
填目标服务器的 SSH 信息，自动装好青源 agent 并注册成 systemd 常驻服务。 密码只在这次安装里用一次；勾选"记住密码"才会加密保存，方便以后一键重装。
