‹ 设置
这是首次配置：先到「登录」设好密码，再到「部署」给机器装青源 agent。之后这个页面一直在 /settings。 如果看板打算公网暴露，请先完成登录密码，否则这里对任何能访问到的人都是开放的。
告警阈值
CPU、内存、磁盘使用率超过这个百分比就告警；看板上的红色也用同一套阈值。
飞书
群设置 → 群机器人 → 添加"自定义机器人"，把 Webhook 地址填在这里。
测试用的是已保存的配置，改了 Webhook 要先保存。
邮件
上报过的机器会一直被盯着，离线超过 3 分钟就告警。机器退役或卸掉 agent 后在这里移除； 移除后如果它又开始上报，会自动回到列表里。
一键部署青源 agent
填目标服务器的 SSH 信息，自动装好青源 agent 并注册成 systemd 常驻服务。 密码只在这次安装里用一次；勾选"记住密码"才会加密保存，方便以后一键重装。
